# Paul & Jack Bakery Demo Website

A demo website for [Paul & Jack Bakery & Café](https://www.facebook.com/paulandjackbakery/) — an artisan bakery with locations in Wake Forest and Downtown Raleigh, NC.

## Pages

- **Home** (`index.html`) — Hero, story, featured pastries, reviews, and order preview
- **Menu** (`menu.html`) — Croissants, cakes, coffee, and seasonal favorites
- **Visit Us** (`visit.html`) — Both locations, hours, and amenities
- **Order** (`order.html`) — DoorDash delivery and pickup link

## Features

- Responsive design with a warm European patisserie aesthetic
- Live open/closed status based on Eastern Time hours
- DoorDash ordering integration for the Wake Forest location
- Content sourced from the bakery's Facebook page and public listings

## Local Preview

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from branch** → `main` → `/ (root)`
4. Your site will be live at `https://mnkuroda.github.io/paulandjacksbakerydemo/`
